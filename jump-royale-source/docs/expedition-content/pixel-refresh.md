# 16-bit character and forest refresh

The built-in image_gen tool redrew Captain Marlow, Cosmo and Mochi Rose using the existing rat/skeleton 16-bit sheets as style references. The replaced expedition sheets supplied character identity and pose order. Source images are in `source/`. `scripts/compile-expedition.cjs` finds transparent row gutters, packs each character at 64px per frame with 24-color pose palettes, and exports an integer 4x nearest-neighbor sheet. Runtime filtering also uses nearest neighbor. Production assets are `forge-climb-royale/assets/reforged/cosmetics/{pirate,astro-monkey,axolotl}-expedition-16.png`.

Axolotl and rat both render at 16.1 world pixels tall in the idle pose; pirate and monkey are 28. Cosmetic scaling is shared by play and previews, while physics bodies remain identical.

Ten occasional inverted solid shelves span forest crossings. Their 180-degree art rotation puts the moss cap on the underside. All 167 main jumps and 20 alternative branches remain reachable, all four expert bots finish before the flood, and explicit upward collision tests cover every ceiling. Bots avoid targeting the tops of overhead obstacles. The hole has a newly generated moss-slate texture, an open transparent notch, and a collision floor measured from the final texture (46.5 world pixels deep).

Validation: client/server typecheck, full npm test suite, forest route/bot/collision suite, hosted production build, and browser verification of 48 animation frames, 27 sequences, nearest filtering, equal rat/axolotl heights, ten rotated roofs and no browser errors. Browser captures are in the local ignored `qa/` directory.

## Final character prompt set

Shared prompt: Use case: style-transfer. Production Jump Royale 16-bit sprite sheet. Image 1 is the STRICT pixel art style reference; image 2 is the character identity and 16 pose layout to replace. Redraw image 2 as true low-resolution SNES-style pixel art matching image 1, NOT high-resolution illustration with pixel filter. [Subject below.] Exactly 4 columns x 4 rows, 16 separate complete sprites, centered within equal cells, ample transparent gutters, no touching cells. Same direction facing right, same proportions throughout. Row 1: idle, blink idle, half crouch, deep charge crouch. Row 2: rising jump, falling, squat landing, sitting defeated. Row 3: four distinct walk-cycle poses alternating feet. Row 4: arms raised victory, victory hop, wave, idle. Each sprite should look authored on a 48x48 pixel grid with blocky single-pixel dark contours, flat limited palette (approximately 20 colors), at most three shades per material, restrained facial features. Crisp hard square pixel edges, no anti-aliasing, no gradients, no fur texture, no painterly microdetail, no glossy 3D or anime look. Truly transparent background, no checkerboard, no floor shadow, no text, no grid lines. All extremities fully within their own cells. Use same body scale in every frame, keep crouched poses shorter.

- Pirate: Captain Marlow: a small pirate with black tricorn, red feather, red coat, dark boots. Simplify outfit ornament into a few pixels.
- Monkey: Cosmo: a brown monkey in a cream spacesuit with muted teal patches, small round glass helmet and curled tail. Glass helmet uses a single pixel highlight, no glossy rendering.
- Axolotl: Mochi Rose: a SMALL pink axolotl with coral external gills, tapered tail and tiny teal neckerchief. Compact small-animal body like the reference rat, tiny dot eyes, not oversized anime eyes.

## Final hole prompt

Remake the U shaped platform in image 2 using the small dense irregular slate-rock TEXTURE SCALE of image 1. Strict 16-bit forest game sprite. Preserve image 2's U silhouette and transparent open center. Crucial correction: rocks must be THREE TIMES SMALLER than image 2, many thin irregular broken slate shards and dense subtle granular rock texture, roughly 15-20 small stones across EACH side shelf. No giant round bulging rocks or toy boulders, no thick cushion moss. Thin pale mint green grassy cap, subtle dark olive moss, dark desaturated blue-teal rock, very few tiny crystals. Image 1 is the EXACT material reference, match it closely. Flat left/right top ledges, rectangular center notch from37% to63% width and half way down the height. Crisp horizontal side view, organic irregular bottom edge. True transparent background and notch; no objects or colored patches in notch, no red, no lines above notch, no shadow, no text. Wide landscape sprite.

The selected generated source is `source/forest-hole.png`. It is alpha-trimmed and resized to 1024px width with nearest-neighbor sampling, then exported as lossless WebP to `forge-climb-royale/assets/forest-ai/bucket-16.webp`.
