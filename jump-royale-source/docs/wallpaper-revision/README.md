# Wallpaper revision

Pirate: on-deck close-up with a clickable cannon, ballistic cannonball, muzzle flash, powder smoke, deck dust and synthesized cannon report using the existing effects volume setting. Aria is human-sized alongside it. New wallpaper instruction panels are removed; existing bubble and breeze actions now use scene hotspots.

Moon: regenerated sparse starfield and cropped lunar cap, circular surface traced from image. Approximately 30% of the moon diameter is visible; remainder can be traversed below screen. Radial gravity reduced from 420 to 150; full-charge airborne time is 4.23 seconds. Moon jumps and other new wallpapers support one-way UI platforms including the name card and every visible menu button.

Validation: production build, 12 visible controls land/pass-through, cannonball and smoke, full 7-radian orbit and offscreen travel, moon UI landing/walk-off, all five new wallpapers, portrait/landscape, no browser exceptions. Browser regression: scripts/browser-wallpaper-revision.mjs.

Built-in image_gen prompts (final assets in forge-climb-royale/assets/menu/wallpapers):
- corsair-cove.png: Detailed painterly pixel art, camera ON a full-sized pirate ship wooden deck, large foreground black iron cannon on wheels facing up-right, close mast and rigging, sails overhead, twilight teal sea beyond, uncluttered right area for menu. No characters, text, labels, UI or watermark.
- moonwalk.png: Detailed painterly pixel art, almost black sparse starfield with large grey cratered moon upper cap rising from below the frame; most of the sphere offscreen. Clean circular surface for walking. No astronaut, Earth, nebula, text, UI or watermark.
