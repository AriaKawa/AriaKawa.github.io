# Complete 16-bit roster

Added 64px, 12-frame sheets for Spore Scout, Biscuit, Mochi, Pip, Rattle and Roo. Generated using ImageGen, keyed to transparency and imported with nearest-neighbor scaling. Idle frames are identical; movement, crouch, flight, landing and defeat retain distinct poses. Existing original skins remain available.

All characters now have a 16-bit costume. New options use the established 5-gold HD costume ownership flow and Covert Mystery Box pool. Animal hats compose at the HD scale.

Validation: typecheck, full npm test suite, social/loot tests, hosted build, and browser-roster.mjs (complete roster coverage, loot entries, 288 frame/hat combinations, zero browser errors). Visually inspected rendered sprites and all three animal hats.
