# AI-generated Long Mountain environment

All ten regional backgrounds, forty platform variants and six props were generated with the built-in image_gen tool on 2026-09-15, using the foothills atlas as a style reference. Original prompts and unmodified alpha-bearing PNG atlases are retained in jump-royale-source/docs/ai-art-prompts.json and docs/ai-source/. The compiler only extracts atlas cells, preserves alpha and exports WebP. No SVG or programmatically illustrated scenery is used by this map renderer. Existing characters, UI and other maps retain their existing assets.
