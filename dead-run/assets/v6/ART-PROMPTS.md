# Animation pass · v6

Generated with the built-in image generation tool for Dead Run. Selected originals are retained here; prior versions remain unchanged. No CLI/API fallback was used.

144 prepared frames cover three weapon families (run, aim, jump), minigun (aim/jump), shieldboard (ride/jump), four infected loops, and a shared gait sheet. Runtime legs use symmetric four-phase half-strides from the gait sheet so the feet share timing and aiming does not reset locomotion. Weapon hands remain in the original orientation. Jump frames preserve the tucked silhouette at the apex. `prepare-art-v6.cjs` crops connected figures, applies a shared scale, and aligns the head/feet; `alignment.json` records the prepared frames. The shader adds the stim hue to the character alpha. Crumble particles sample the original destroyed prop textures.

The shotgun correction supplies only run frames; its original forward-aim and jump rows are retained. Zombie sheets use the selected cycle revisions. Exact generation provenance is also in `../../v6-generation.json`.
