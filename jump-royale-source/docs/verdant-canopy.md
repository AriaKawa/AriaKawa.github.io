# Verdant Canopy release

Built-in image_gen generated four assets, saved under `forge-climb-royale/assets/jungle-hd/`: `background.webp`, `riverbank.webp`, `vine.webp`, `alligator.webp`. Original generated alpha was preserved; the vine and alligator were cropped for sprite framing and converted to WebP. The backdrop uses its original aspect ratio and smooth display scaling.

Controls: spawn on the right, jump left into the swinging vine to grab automatically. W/S or Up/Down climb. A new Space press releases with tangential swing velocity; a 0.65-second cooldown prevents immediate reattachment. The shared simulation handles practice and hosted multiplayer. Vertical controls are forwarded by multiplayer guests. The first two ledges form a left/right opening crossing. A sleeping alligator breathes on the starting riverbank.

Validation: TypeScript checks, production build, existing regression suite, test-vines.ts (right-spawn catch, both climbing directions, exact tangential release velocity, cooldown, left-bank landing), browser-vines.mjs (real keyboard controls, guest vertical-input serialization, 390/768/1440 widths and no browser/request errors).
